# Chen — Search Log

לוג חיפושים של חן. כל חיפוש מתועד בפורמט קבוע מתחת. חן בודקת קובץ זה לפני כל חיפוש חדש (Grep על מילות מפתח) כדי למנוע חזרה על עבודה.

## פורמט entry

```markdown
## YYYY-MM-DD HH:MM | <נושא החיפוש>
**מילות מפתח:** keyword1, keyword2
**שאילתות שנעשו:** "query 1", "query 2"
**מקורות שנמצאו:**
- [כותרת](URL) - איכות: ⭐⭐⭐⭐ - <הערה>
- [כותרת](URL) - איכות: ⭐⭐⭐ - <הערה>
**נבחר:** [כותרת](URL) — <משפט הסבר>
**קובץ ב-Content:** `Content/<YYYY-MM-DD>-<slug>.md`
---
```

## כללים

- ה-entry החדש ביותר נכנס **בתחתית** — קריאה top→bottom = היסטוריה כרונולוגית.
- מילות מפתח חייבות להיות כאלה שיעלו ב-Grep — שם מותג/טכנולוגיה/נושא, לא שמות תואר כלליים.
- בנושא דינמי (חדשות/מחירים/release notes) — מחפשים מחדש גם אם יש entry קודם, אבל מעדכנים את ה-entry או מוסיפים אחד חדש שמפנה לקודם.
